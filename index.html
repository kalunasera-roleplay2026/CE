✅ CARA 1: SIDER LIVECPK (REKOMENDASI - GAK PERNAH ERROR)

Gak perlu CRI Packed File Maker. Gak perlu DpFileList. Cuma copy folder. 100% work di SmokePatch, PTE, T99, EvoWeb.

1. Klik tombol di atas -> download edit.bin
2. Bikin folder: PES 2017\sider\livecpk\BAL_127_GOD\common\character\edit\data\
3. Taruh edit.bin ke dalam data\
4. Buka sider.ini, tambah baris: cpk.root = ".\livecpk\BAL_127_GOD"
5. Jalankan sider.exe baru buka PES
📦 CARA 2: CPK DPFILELIST (KALAU MAU PAKAI DpFileList)

Ini cara bener pakai CRI Packed File Maker biar gak error Failed analyze.

Langkah BENER (Lihat foto kamu):
